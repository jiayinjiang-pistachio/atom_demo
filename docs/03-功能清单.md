## 14. 明确未实现 / 不在范围（集中披露）

### 14.1 未实现（可能影响体验或上线安全）

1. 在线代码编辑（CodeMirror + 保存为新版本）。
2. 每日 guest 生成配额强制。
3. IP / 网关级限流。
4. run 墙上时间上限。
5. metrics / 告警 / 运行聚合报表。
6. 项目重命名界面入口。
7. Markdown 安全渲染（markdown-it + DOMPurify）。
8. 移动端对话/预览/文件 Tab。
9. 项目列表分页与搜索。
10. 任意两版本对比选择器。
11. 分享访问统计与二维码。
12. Playwright E2E。
13. CI 工作流（GitHub Actions 等）。

### 14.2 不在本期范围

1. 注册 / 登录 / OAuth / 团队协作 / 权限。
2. 支付 / 计费。
3. 一键部署生成应用到第三方平台。
4. Redis / 消息队列 / 对象存储。
5. WebSocket / 前端直连 LLM。
6. 服务端执行生成代码或 SSR。
